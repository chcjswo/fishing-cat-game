# 팝업 고양이 확대와 여백 유지

- [x] 1. 확대 크기와 팝업별 상하 여백을 정한다.
- [x] 2. 모든 팝업 고양이를 약 11% 확대하고 상하 여백·작은 화면 검증 후 커밋한다.
- [ ] 3. 앱 자산을 동기화하고 반영 결과를 확인·커밋한다.

공통 표시 영역을 108×112 → 120×124px로 늘린다. 제목 아래 패딩은 유지하고, 일시정지/게임오버 고양이 아래 간격을 24px로 확보한다. 시간 종료의 기존 24px 간격은 유지한다. 클리어 고양이는 별과의 위 간격을 34px로 늘려 위로 뛰는 애니메이션 중에도 24px 이상 유지하고 아래 여백도 24px로 확보한다. 카드 높이는 내용에 맞춰 늘어난다.

검증: `node test/game_js/popup_consistency.test.cjs` 통과. 실제 글꼴의 320×568/390×844/640×1024 화면에서 일시정지·시간 종료·게임오버·별 1~3개 클리어의 크기 및 위아래 여백, 카드 잘림, 기존 버튼 간격 32px 유지를 확인했다. 390×844 캡처에서도 고양이와 제목/점수의 간격을 확인했다.
