# 하트 회복 문구 표시 개선

- [x] 1. 회복 문구 위치와 고양이의 표시 순서를 확인한다.
- [x] 2. 문구를 위로 옮기고 고양이 앞에 표시한 뒤 앱 자산을 동기화하고 검증한다.

현재 회복 문구는 고양이 상단보다 30px 아래에서 시작한다. 부모 효과 레이어의 z-index는 9이고 고양이는 16이라 가려진다. 회복 문구를 80px 위로 올리고, 기존 전경 효과 레이어(z-index 17)에 표시한다. 생명이 가득 찼을 때 하트의 +300 문구도 같은 위치에 표시한다.

완료: 회복 문구는 고양이 상단보다 50px 위에서 시작하고 전경 레이어에 표시된다. 화면 전환 시 새 레이어의 회복 문구도 함께 정리한다. `dart run tool/sync_game_assets.dart`로 앱 자산을 갱신했다. 앱 번들을 헤드리스 브라우저의 640×1024/390×844 화면에서 실행해 시작 위치, 고양이 앞 표시, 하트 회복과 +300 보너스, 화면 전환 시 제거를 확인했다. `git diff --check` 통과.
