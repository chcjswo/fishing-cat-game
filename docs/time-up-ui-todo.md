# 회복 문구 및 시간 종료 팝업 조정

- [x] 1. 현재 위치·제목 스타일·결과 버튼 구조를 확인하고 작업을 나눈다.
- [ ] 2. 회복 문구를 현재보다 12px 아래로 조정하고 검증·커밋한다.
- [ ] 3. 시간 종료 팝업의 제목과 세로 3단 버튼을 정리하고 작은 화면에서 검증·커밋한다.
- [ ] 4. 앱 자산을 동기화하고 관련 회귀 검사를 실행해 결과를 기록·커밋한다.

확인: 시간 종료 제목은 공통 결과 제목의 44px/자간 3px을 사용한다. 일시정지 제목은 36px/자간 1px, 게임오버 제목은 38px로 별도 조정돼 있다. 시간 종료도 일시정지 제목과 동일한 글꼴·크기·자간을 사용한다. 시간 종료 전용 클래스로 결과를 구분해 클리어/게임오버 배치는 유지한다.

설계: 시간 종료에서는 비활성 별 3개를 숨기고 고양이·점수 영역을 압축해 버튼 공간을 확보한다. 일시정지와 같은 카드 폭과 버튼 높이로 처음으로→다시 도전→점수 공유를 세로 배치한다. 브라우저에서는 기존 정책대로 점수 공유를 숨긴다.
