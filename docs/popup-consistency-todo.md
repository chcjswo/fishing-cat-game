# 팝업 고양이와 버튼 간격 통일

- [x] 1. 팝업별 고양이 크기·버튼 간격·제목 여백을 비교한다.
- [x] 2. 고양이 표시 크기를 통일하고 일시정지 제목 아래 여백을 늘려 검증·커밋한다.
- [x] 3. 버튼 간격을 공통으로 정하고 시간 종료 높이·게임오버 안내 배치를 조정해 검증·커밋한다.
- [x] 4. 앱 자산을 동기화하고 관련 팝업 회귀 검사 결과를 기록·커밋한다.

현재 고양이는 일시정지 80×90, 시간 종료/게임오버 108×112, 클리어는 상태별 폭 130~160px로 다르다. 모두 108×112px 표시 영역과 object-fit:contain을 사용해 비율을 유지한다. 일시정지 상단 패딩은 52→80px로 늘린다.

버튼 간격은 기존 일시정지 24px을 기준으로 여유 8px을 더한 32px로 공통화한다. 일시정지·확인창·결과·공유·게임오버의 주 동작 버튼에 같은 값을 적용한다. 시간 종료는 상하 패딩과 내용 여백도 늘린다. 광고 부활 안내는 버튼 앞에 배치해 광고/다시 시작/메인 버튼 사이에도 동일한 간격을 확보한다.

2단계 검증: 390×844 화면에서 일시정지 제목과 고양이 사이 여백, 별 1/2/3개 클리어 상태의 고양이 표시 크기 108×112 일치를 확인했다.

3단계 검증: `popup_consistency.test.cjs`로 실제 글꼴·320×568/390×844/640×1024에서 모든 고양이 표시 크기, 제목 아래 여백, 일시정지/확인창/시간 종료/게임오버/클리어/공유의 버튼 간격 32px 일치를 확인했다. 게임오버는 광고 준비 전/후, 클리어는 별 1~3개 상태를 검사했다. 카드 등장 애니메이션이 끝난 뒤 전체 크기와 잘림을 검사했다. 시간 종료 상하 패딩은 80/44px로 늘리고, 고양이 아래·점수 아래 여백도 24/36px로 늘렸다. 일시정지와 시간 종료 실제 캡처를 비교해 균형을 확인했다.
